iterami/Docs.htm/Standards/Contributing
  1. Join the public iterami Dicussions on GitHub to discuss iterami repos.
  2. Discussions, issues, and pull requests to solve open issues labeled as bug or enhancement.
    • Issues can be about anything and assigned to anybody.
    • Issues about something handled by iterami/common should be reported in that repo, instead of in a repo that utilizes that common code.
    • Pull requests can be made about anything, but are not assigned to anybody or labeled.
    • Pull requests must conform to the license and coding standards of their respective repo.
  3. Code additions and improvements to core iterami repos:
    1. iterami/common needs code additions/improvements.
    2. iterami/Docs.htm needs additional and improved docs for all repos.
  4. Code additions and improvements to all other iterami repos, all with equal priority:
    • iterami/UnitConverter.htm needs more units and current conversions to be verified.
  5. Use, play, and enjoy iterami repos!
