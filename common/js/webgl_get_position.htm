iterami/Docs.htm/common HTM Repos/webgl.js/webgl_get_position(entity)
  • If "entity" is a character, returns current position xyz.
  • If "entity" is an entity, loops through attachments until reaching a character, the original entity, or an unattched entity. Attach offsets are added together, combined with the final entity's position xyz, and returned.
Arg Default Type
entity character/entity object
