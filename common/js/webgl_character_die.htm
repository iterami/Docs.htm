iterami/Docs.htm/common HTM Repos/webgl.js/webgl_character_die(id)
  • Causes the specified character to die:
    1. Life is set to 0.
    2. If the character has more than 0 lives, then 1 is lost.
    3. If the character does not have 0 lives remaining, then they respawn via webgl_character_spawn(id).
Arg Default Type
id webgl_character_id string ID
