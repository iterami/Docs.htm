iterami/Docs.htm/common HTM Repos/core.js/core_repo_init(args)
  • Called by repo-specific repo_init() function.
  • Runs additional init functions in "core_init_todo" and then deletes it.
  • Sets up various repo-specific things needed for project function.
  • If "menu" or "menu_lock" are true, then the menu is open when the repo loads.
  • If "storage_controls" is not false, then a tab with settings for keyboard and pointer controls will be created.
  • If "storage_controls" is an object, then its properties can be used to overwrite "core_key_rebinds" values with custom objects.
