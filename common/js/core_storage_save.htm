iterami/Docs.htm/common HTM Repos/core.js/core_storage_save(args)
  • Saves current valid localStorage input values to localStorage.
  • Saves all by default, but can also only save specific keys.
  • Invalid input values are reset to their currently saved value.
  • Can optionally call core_keys_rebind() to update bound keys.
Arg Default Type
keys false boolean false or array of strings
rebind true boolean
