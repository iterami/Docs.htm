iterami/Docs.htm/common HTM Repos/audio.js/audio_start_at(args)
  • Adds or modifies panner position properties for the specified audio.
  • Calls audio_start(id) to play the specified audio.
  • Can overwrite the current listener orientation.
Arg Default Type
forwardX audio_listener.forwardX number between -1 and 1
forwardY audio_listener.forwardY number between -1 and 1
forwardZ audio_listener.forwardZ number between -1 and 1
id string ID
positionX 0 number
positionY 0 number
positionZ 0 number
