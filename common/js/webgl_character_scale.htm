iterami/Docs.htm/common HTM Projects/webgl.js/webgl_character_scale(args)
  • Multiplicatively scales all entities attached to the specified character via webgl_entity_scale(args), without modifying their own scale properties.
  • 1 is the default scale and axes with a value of false are not scaled.
Arg Default Type
id webgl_character_id string ID
set false boolean
x false boolean false or number
y false boolean false or number
z false boolean false or number
