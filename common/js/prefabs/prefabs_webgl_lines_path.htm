iterami/Docs.htm/common HTM Repos/webgl.js Prefabs/prefabs_webgl_lines_path(args)
  • Creates a line loop connecting all points in the specified path.
  • Args will be used in entity creation after being cleaned up by webgl_prefab_args(args).
  • The "colors" arg defaults to [[1, 1, 1, 1]] if it remains empty.
  • Each color in the "colors" arg will be used sequentially and loop if there are more points than colors.
Arg Default Type
character webgl_character_base string ID
colors [] array of array of numbers 0-1
groups [] array of strings
path string ID
prefix String(entity_id_count) string ID
