iterami/Docs.htm/common HTM Projects/webgl.js Prefabs/prefabs_webgl_cuboid_tree(args)
  • Creates a cuboid tree prefab with the specified properties.
  • Position is the center of the bottom face of the trunk.
  • Args will be used in entity creation after being cleaned up by webgl_prefab_args(args).
Arg Default Type
character webgl_character_id string ID
groups [] array of strings
leaf-collision true boolean
leaf-color [0, 1, 0, 1,] array of numbers
leaf-size-x 10 number
leaf-size-y 10 number
leaf-size-z 10 number
leaf-texture 'lavaleaf.png' string
prefix entity_id_count string ID
trunk-collision true boolean
trunk-color [.8, .4, 0, 1,] array of numbers
trunk-size-x 2 number
trunk-size-y 10 number
trunk-size-z 2 number
trunk-texture 'wood.png' string
