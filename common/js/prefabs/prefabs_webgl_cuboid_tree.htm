iterami/Docs.htm/common HTM Repos/webgl.js Prefabs/prefabs_webgl_cuboid_tree(args)
  • Creates a cuboid tree prefab with the specified properties.
  • Position is the center of the bottom face of the trunk.
  • Args will be used in entity creation after being cleaned up by webgl_prefab_args(args).
Arg Default Type
character webgl_character_base string ID
groups [] array of strings
leaf_collision true boolean
leaf_color [0, 1, 0, 1,] array of numbers
leaf_size_x 10 number
leaf_size_y 10 number
leaf_size_z 10 number
leaf_texture 'lavaleaf.png' string
prefix String(entity_id_count) string ID
trunk_collision true boolean
trunk_color [.8, .4, 0, 1,] array of numbers
trunk_size_x 2 number
trunk_size_y 10 number
trunk_size_z 2 number
trunk_texture 'wood.png' string
