iterami/Docs.htm/common HTM Repos/tables.js/tables_sort(element, column, direction)
  • Called by sorting buttons to sort a column of a specific table.
  • First, numerical values are formatted via tables_format_number(value) and sorted, then followed by sorted text values.
  • If the table contains multiple <tbody> elements, then the last one will be sorted.
Arg Default Type
element HTML element
column string ID
direction 1 for ascending, 0 for descending
