iterami/Docs.htm/common HTM Repos/webgl.js/webgl_pick_event(args)
  • Handles the buffer and sync, along with the "cursor", "x", and "y" properties, when picking via webgl_pick(cursor) is successful.
  • If "cursor" is true, then the cursor will be changed to "pointer" when hovering over a pickable entity instead of triggering picking events.
  • If "cursor" is false, then optional events are triggered on a successful pick.
