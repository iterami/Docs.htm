iterami/Docs.htm/common HTM Repos/webgl.js/webgl_timer_handle(timer)
  • If "timer" is active, then decreases remaining "timer.frames" by 1.
  • If "timer.frames" <=0:
    • and "timer.repeat" is >0, then handle "timer.event_repeat" events.
    • and "timer.repeat" is <=0, then handle "timer.event_end" events.
  • Events are handled by webgl_event(args).
Arg Default Type
timer object
