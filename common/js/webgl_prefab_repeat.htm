  • Prefab used to randomly place repeated copies of a prefab within any number of areas with their own optional properties.
  • Areas can have optional objects to apply properties to created "characters" and prefab "properties".
  • If the "characters" arg is not false, new characters will be created for each prefab and will inherit the specified properties, unless an area specifically has its "characters" property set to false.
  • You can repeat entities without using a prefab by setting the "type" arg to "webgl_entity_create" to pass the "properties" to webgl_entity_create(args) as its args.
