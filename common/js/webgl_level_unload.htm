iterami/Docs.htm/common HTM Projects/webgl.js/webgl_level_unload(base)
  • No args.
  • Deletes all characters, entities, particles, and paths.
  • If "base" is true, returns entities and properties of "webgl_characters[webgl_character_id]" for optional use in webgl_level_init(args), or otherwise returns an empty object.
