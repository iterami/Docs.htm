iterami/Docs.htm/common HTM Repos/core.js/core_requestpointerlock(element)
  • Attempts to request pointerlock on an element, such as a canvas.
  • Does nothing if:
    1. The core menu is open.
    2. "core_mobile" is true.
    3. An element currently has pointerlock.
    4. The escape key is being actively pressed.
  • Any errors that occur are silently ignored.
Arg Default Type
element HTMLElement
