iterami/Docs.htm/common HTM Projects/audio.js/webgl_audio(args)
  • Calculates the relative position of the audio emitter compared to the position of the active character.
  • Calls audio_start_at(args) to play the specified audio from the target position.
  • Can init new audios via the "audio" arg.
Arg Default Type
audio false boolean false or object
divider_x 50 number
divider_y 50 number
divider_z 50 number
id string ID of the audio
target string ID of character or entity
type 'webgl_characters' 'entity_entities' or 'webgl_characters'
