iterami/Docs.htm/common HTM Repos/core.js/core_type_convert(args)
  • Converts variable depending on template variable type in order:
    1. If the template type matches the value type, returns the value.
    2. If the template is a boolean, returns true if the value equals the string "true".
    3. Otherwise returns the value coercered to the template type constructor, such as String(value).
Arg Default Type
template any
value any
