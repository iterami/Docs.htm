iterami/Docs.htm/common HTM Repos/webgl.js/webgl_texture_init(id)
  • Creates a texture based on an image in "webgl_images" and stores it in "webgl_textures".
  • If the texture does not already exist, inits the image from "webgl_uris[image]" and stores it in "webgl_images[image]" for use during texture init.
Arg Default Type
id string ID
