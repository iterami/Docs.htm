iterami/Docs.htm/common HTM Repos/webgl.js/webgl_collision(args)
  • Checks for collision between characters/entities.
  • The "change" arg object is used to keep track of changes to the character's original "change_position_x" and "change_position_z" in order to account for modified position changes while colliding with an entity on the Y axis.
Arg Default Type
change object
collider character/entity object
target entity object
