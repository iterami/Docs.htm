iterami/Docs.htm/common HTM Repos/webgl.js/webgl_level_export()
  • No args.
  • Converts the current level to JSON and returns it:
    • WebGL properties.
    • Characters and their entities.
    • Default and custom groups, excluding those automatically created to handle character entities.
    • Particles.
    • Paths.
    • Textures, except for "default.png".
  • Some properties are not included in the export:
    • Any entity property that matches the default value.
    • Additional entity properties: normals, vao, vertices_length
