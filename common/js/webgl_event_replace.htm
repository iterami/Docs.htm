iterami/Docs.htm/common HTM Repos/webgl.js/webgl_event_replace(args)
  • Called by webgl_event(args) to recursively replace strings in event objects before handling:
    • "_character": repalced by the ID of the event parent "attach_to" property, or ID if it doesn't exist.
    • "_self": replaced by the ID of the event parent.
    • "_target": replaced by the ID of the event target.
Arg Default Type
modify event object
replace object of strings to replace
