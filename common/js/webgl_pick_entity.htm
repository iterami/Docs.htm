iterami/Docs.htm/common HTM Projects/webgl.js/webgl_pick_entity(args)
  • Requires the "webgl_propreties['picking']" to be at least 1 before picking can be done.
  • Temporarily draws entities using their "picking" color and determines which entity is picked.
  • The "cursor" arg dictates if the cursor should be changed to "pointer" when hovering over a pickable entity.
  • Returns picked entity or false if no entity is picked.
  • Triggers optional events and returns the entity object if an entity is picked.
Arg Default Type
cursor false boolean
x core_pointer['x'] number
y core_pointer['y'] number
