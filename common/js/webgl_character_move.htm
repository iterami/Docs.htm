iterami/Docs.htm/common HTM Repos/webgl.js/webgl_character_move(args)
  • Handles moving a character within 3D space.
  • Maintains y position unless specifically changed.
  • The "angle" arg is either true and uses the character's "rotate-y" to determine movement direction, or specifies the angle that should be used instead.
Arg Default Type
angle true boolean true or number 0-360
id webgl_character_id string ID
speed 1 number
strafe false boolean
y false boolean false or number
