iterami/Docs.htm/common HTM Projects/webgl.js/webgl_character_init(args)
  • Creates a character, its entities, and its vehicle.
  • Characters that aren't "static" are spawned upon init via webgl_character_spawn(id), which will set any properties within the character's optional "spawn" property.
  • Args will be passed directly to the character object to allow for custom properties.
  • Some args are deleted before becoming character properties:
    • The "entities" arg contains the entities that should be created after this character is created.
    • The "randomize" arg will create a randomized body for the newly created character.
  • If the "character" property in "vehicle-stats" is not false, then the specified character will enter the vehicle automatically.
