iterami/Docs.htm/common HTM Projects/webgl.js/webgl_character_spawn(id)
  • Resets various character properties:
    • Rotation and position change are set to 0.
    • Current life is set to max life.
    • Jump allow is set to false.
  • Character properties are overwritten by the character's optional spawn properties and the level's default spawn properties.
Arg Default Type
id webgl_character_id string ID
