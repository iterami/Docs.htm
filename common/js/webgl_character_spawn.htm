iterami/Docs.htm/common HTM Projects/webgl.js/webgl_character_spawn(id)
  • Resets various character properties:
    • Rotation and translation change are set to 0.
    • Current life is set to max life.
  • Character rotation/translation and camera rotation are set to the character's optional spawn properties, or to the level's default spawn properties.
Arg Default Type
id webgl_character_id string ID
