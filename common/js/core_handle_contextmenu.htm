  • If "core_pointer.todo.contextMenu" exists, then the context menu will be prevented from appearing.
  • Context menu always appears when the menu is open, or when "shift + right click" is used.
  • Calls "contextmenu" event todo(), and if it doesn't return anything, this function returns false.
