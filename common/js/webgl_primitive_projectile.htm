iterami/Docs.htm/common HTM Repos/webgl.js/webgl_primitive_projectile(args)
  • Fires a projectile that is created when webgl_projectile(args) does not specify a projectile ID.
  • Position, rotation, and camera rotation are inherited from the character that fired the projectile.
  • Additional default args are handled by webgl_prefab_args(args).
Arg Default Type
character string ID
groups [] array of strings
prefix String(entity_id_count) string ID
speed 1 number
