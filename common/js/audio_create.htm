iterami/Docs.htm/common HTM Repos/audio.js/audio_create(audios)
  • Tests
  • Adds an audio object to "audio_audios" with the following properties:
    Properties Default Type
    duration .1 number
    frequency 100 number
    panner false boolean false or object
    type 'sine' string:
    • 'sawtooth'
    • 'sine'
    • 'square'
    • 'triangle'
  • A default "boop" audio is created when the file is loaded.
  • Created audios can be started via audio_start(id) or audio_start_at(args).
Arg Default Type
audios object of objects
