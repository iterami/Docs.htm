iterami/Docs.htm/common HTM Projects/webgl.js/webgl_primitive_frustum(args)
  • Creates a frustum primitive with specified properties.
  • Additional default args are handled by webgl_prefab_args(args).
  • Position is the center of the bottom of the frustum.
  • If the "color_bottom" or "color_top" arg arrays are empty then a random color will be used.
Arg Default Type
bottom true boolean
character webgl_character_id string ID
color_bottom [] array of numbers
color_top [] array of numbers
groups [] array of strings
length 2 number
middle true boolean
points 8 number
prefix entity_id_count string ID
size_bottom 2 number
size_top 2 number
top true boolean
