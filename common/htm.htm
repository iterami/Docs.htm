Using and Updating:
  • If your repo is being hosted on GitHub Pages, you should use a fork of iterami/common:
    • Update your fork by using iterami/Scripts/iterami/common-fork-rebase.sh.
  • If your repo is being hosted on a different server, you should upload the iterami/common files:
    • You do not need to upload the .git folder.
    • Clone iterami/common via git. Pull and upload any changed files to your server.
    • Your iterami/common folder does not need to be in a particular location, as long as the paths in your <script> tags are correct.
